2. RANDOM SEED AND THE EXACT SAMPLING RULE
------------------------------------------------------------------------
seed = 21 samples = 16 frame = 60
Per sample i the exporter builds its own generator:
rng = random.Random((seed << 20) + i)
and then draws, in this order:
az = rng.uniform(0, 2*pi) camera azimuth
el = radians(rng.uniform(cam_elev_lo, cam_elev_hi))
rad = rng.uniform(radius_lo, radius_hi)
saz = rng.uniform(0, 2*pi) sun azimuth
sel = radians(rng.uniform(sun_elev_lo, sun_elev_hi))
cover = rng.uniform(cloud_lo, cloud_hi)
camera position:
cam = (tx + rad*cos(el)*cos(az),
ty + rad*cos(el)*sin(az),
tz + rad*sin(el))
sun direction is the direction the LIGHT TRAVELS (down = negative z):
sun = (-cos(sel)*cos(saz), -cos(sel)*sin(saz), -sin(sel))
Each sample gets its own world file with Viewpoint and OmniSimSun rewritten,
so the camera poses, sun vectors and cloud covers are reproducible exactly
from (world, seed, samples). The IMAGES are only as deterministic as the
renderer.

3. DOMAIN-RANDOMISATION PARAMETERS AND RANGES
------------------------------------------------------------------------
parameter range used exporter parameter
camera orbit radius 1.8 - 6.0 m --radius 1.8,6.0 (default 7,15)
camera elevation 3 - 18 deg --cam-elev 3,18 (default 8,40)
camera azimuth 0 - 360 deg not settable; always the full circle
sun elevation 12 - 65 deg exporter default --sun-elev 12,65
sun azimuth 0 - 360 deg not settable; always the full circle
cloud cover 0.10 - 0.60 exporter default --cloud 0.10,0.60
camera look-at (0, 0, 0.55) m --target 0,0,0.55
All six draws are uniform. Camera elevation 3-18 deg was chosen to sit at a
rover's eye height. Nothing else is randomised: the board, the distractors,
the materials and the ground are fixed across all 16 samples.

4. CAMERA CONFIGURATION
------------------------------------------------------------------------
render resolution 1896 x 1113
fx = fy 2288.6749860 px
cx, cy 948, 556.5
fov_x 0.785398 rad (45.0 deg)
near / far 0.05 / 1000 m
axes camera +X forward, +Z up (world ENU)
extrinsics per sample: world position plus a row-major 3x3
rotation, in each sample's meta JSON file
annotation resolution 640 x 480 - your vision_control.py sets
FRAME_WIDTH=640, FRAME_HEIGHT=480
resample recipe central crop of the 1896x1113 render to 4:3
(1484 x 1113, x0 = 206), then resize to 640x480:
INTER_AREA for RGB, INTER_NEAREST for the instance map.
Ground truth therefore lives in YOUR pixel coordinates,
not in a rescaled approximation of them.
effective focal after crop and resize: f is about 987 px at 640x480.
depth settings uint16 PNG, millimetres, 0 = no hit, ceiling 65.535 m,
CAMERA-PLANE (planar), not radial. Cross-checked
against the extrinsics on all 16 frames:
planar-minus-Euclidean delta -0.155 to -0.045 m,
mean -0.0848 m, always negative. That is the cosine
term, which is what correctness looks like for an
off-axis target.
